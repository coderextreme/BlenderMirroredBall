3. Custom X3D Export:
Write a function to manually generate an .x3d file to the temporary directory.   Use Physically Based Rendering and Export X3D version 4.0, with possible Sunrize/X_ITE Material Extensions.
Baking: The exporter must bake the vertex animation of the sheet frame-by-frame into an X3D <CoordinateInterpolator> node so the animation plays natively in X3D viewers.
Visuals: Ensure all <IndexedFaceSet> nodes in the X3D file have creaseAngle="3.14159" for smooth shading.
Cleanup: Only export the meshes (Ball, Floor, Sheet) and Lights. Do not export the Hook/Empty helper object.`
